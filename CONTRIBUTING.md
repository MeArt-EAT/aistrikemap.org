# Beitragen zu AIStrikeMap / Contributing to AIStrikeMap

## Deutsch

Vielen Dank für dein Interesse an AIStrikeMap! Es gibt verschiedene Wege, wie du beitragen kannst:

### Vorfälle melden
- Erstelle ein [GitHub Issue](../../issues) mit dem Label `new-incident`
- Beschreibe den Vorfall und nenne mindestens 2 unabhängige Quellen
- Nutze das JSON-LD-Format aus `data/schema/incident-schema.json`

### Quellen ergänzen
- Ergänze Quellen zu bestehenden Vorfällen per Pull Request
- Jede Quelle muss öffentlich zugänglich und überprüfbar sein

### Fehler melden
- Nutze [GitHub Issues](../../issues) mit dem Label `bug` oder `correction`
- Sachliche Korrekturen haben höchste Priorität

### Code beitragen
- Fork → Branch → Pull Request
- Kein Build-System — reines HTML/CSS/JS
- Code-Lizenz: AGPL-3.0
- Daten-Lizenz: CC BY-NC-SA 4.0

### Verhaltenskodex
- Sachlich und respektvoll kommunizieren
- Keine Falschinformationen oder unbelegte Behauptungen
- Quellenbasierte Arbeit

## English

Thank you for your interest in AIStrikeMap! Here's how you can contribute:

### Report Incidents
- Create a [GitHub Issue](../../issues) with the `new-incident` label
- Describe the incident and provide at least 2 independent sources
- Use the JSON-LD format from `data/schema/incident-schema.json`

### Add Sources
- Add sources to existing incidents via Pull Request
- Every source must be publicly accessible and verifiable

### Report Errors
- Use [GitHub Issues](../../issues) with `bug` or `correction` labels
- Factual corrections are highest priority

### Contribute Code
- Fork → Branch → Pull Request
- No build system — pure HTML/CSS/JS
- Code license: AGPL-3.0
- Data license: CC BY-NC-SA 4.0
