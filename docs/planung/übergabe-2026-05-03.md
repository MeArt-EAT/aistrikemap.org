## Methodische Erkenntnisse aus dieser Session-Reihe

1. **Statista-Logik weltweit anwendbar** — "Theorie vs. Praxis" wird durch 3-Ebenen-Layout konkret. Ehrliche Trennung Studie / Plan / Realität.
2. **Globale Verlust-Tracker existieren nicht** (ILO bestätigt). AIStrikeMap kuratiert selbst → Item 105 ist eigene primäre Quelle.
3. **AI-Attribution-Stärke-Skala** (1–5) ist methodisch wertvoll: Konsistente Skip-Entscheidungen bei 5 Companies, Counter bleibt belastbar.
4. **Asymmetrie-Pille** (Pattern via `net_workforce_change == "stable"`) macht den Konflikt zwischen Layoff-Headlines und tatsächlichem Headcount-Effekt sichtbar — bei aktuell 5 von 12 Cases.
5. **Disputed-Attribution-Tag** (Microsoft, Amazon) erlaubt es, methodisch grenzwertige Cases mit Transparenz aufzunehmen statt zu verschweigen.
6. **JSON-Encoding-Falle**: ASCII-Quotes innerhalb deutscher Anführungs-Pärchen brechen JSON-Parser. Lösung: einfache Apostrophes für interne Zitate.
7. **Marker-pro-Land statt Choropleth** als MVP — schlanker (~500 KB GeoJSON gespart), funktional gleichwertig für 6–30 Länder. Choropleth ist v2.

## Projekt-Konventionen (Reminder für nächste Session)

- Pure HTML/CSS/JS, kein Build-Step im Browser, kein npm
- UI und Planungs-Docs **deutsch**, Code-Kommentare englisch
- LICENSE = AGPL-3.0; Daten = CC BY-NC-SA 4.0
- IIFE-Module-Pattern für JS (`const X = (function(){...})()`)
- Cache-busting via `?v=` auf CSS/JS, `Date.now()` auf Daten
- Deploy = push zu `main` → GitHub Pages automatisch
- **i18n-Vollabdeckung Pflicht** (`data-i18n-aria`/`-title`/`-placeholder` für Nicht-Body-Strings)
- **Umlaute korrekt schreiben** (ä/ö/ü/ß), nicht ae/oe/ue/ss; Ausnahmen: technische Identifier (URL-Slugs, JSON-Keys, CSS-Klassen)
- **Insider-Sprache vermeiden** (Lerneffekt 2026-05-03): Konzept-interne Begriffe wie "Bagger-Hebel" gehören nicht in User-sichtbare Strings
- **AI-Attribution-Stärke ≥4 für Counter-Aufnahme** (Item 105 Cases — methodische Konsistenz)
- **Flow-Pattern**: Commit auf branch → `git -C <main-worktree> merge --ff-only <branch>` → `git push origin main`
- **Cases-Workflow**: Datei in `data/labor-impact-cases/`, Schema in `_schema.md`, dann `node scripts/bundle-labor-cases.js` → Aggregate + pro-Land-Bundles werden neu geschrieben
